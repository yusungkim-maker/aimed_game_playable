# 컨텍스트: 코인 경제 시스템(몬스터 처치 → 코인 수집 → 소켓 소환) 0단계 구현 요청

## 배경

Cocos Creator 3.x 기반 3D 플레이어블 광고 프로젝트에 다음 기능 체인을 구현하려고 합니다.

```
몬스터 처치 → 코인 1개 드롭 → 자석 효과로 캐릭터에게 수집됨
→ 캐릭터 등에 쌓임(무제한) → 소켓 근처 도달 시 정해진 개수만큼 흡수
→ 소켓이 목표 개수 충족 시 동료 소환 이벤트 발생
```

## 지금 이 요청의 범위 (0단계: 수치/규칙 확정)

전체 구현에 들어가기 전에 규칙을 먼저 확정하는 단계입니다. 지금까지 확정된 파라미터는 다음과 같습니다.

| 항목 | 값 |
|---|---|
| 몬스터 1마리 처치 시 드롭 코인 수 | 1개 (고정) |
| 자석 효과 발동 반경 | 캐릭터 공격 사거리보다 살짝 짧게 설정 (정확한 수치는 실제 공격 사거리 값 확인 후 결정) |
| 등에 쌓을 수 있는 최대 코인 개수 | 무제한 (캡 없음) |
| 소켓 종류 / 소켓별 필요 개수 / 소환 이벤트 상세 | **아직 미정 — 별도로 소켓 종류와 소환 이벤트를 먼저 정의한 뒤 상세 수치를 산정할 예정. 이 부분은 지금 단계에서 손대지 말 것.** |

## 요청 사항

1. 현재 프로젝트의 씬 구조를 확인해서, 다음을 파악해줘:
   - 캐릭터의 공격 사거리 값이 어느 스크립트/컴포넌트에 정의되어 있는지 (자석 반경을 여기서 참조해서 "약간 짧게" 계산할 수 있도록)
   - 몬스터 사망 판정이 일어나는 정확한 코드 지점(함수명)
2. 위에서 확정된 3가지 파라미터(코인 1개 드롭, 자석 반경 = 공격사거리 × 계수, 스택 무제한)만 가지고, 소켓 로직은 배제한 채로 다음 범위까지만 구현/검증해줘:
   - 몬스터 사망 이벤트 훅 추가 (원본 게임 로직은 건드리지 않고 이벤트만 emit)
   - 코인 오브젝트 스폰 (오브젝트 풀링 적용, 애니메이션 클립 없이 정적 메쉬 + 코드 기반 회전/통통 튐)
   - 자석 수집 로직 (거리 체크 + 이동, 공격 사거리 값을 참조해서 그보다 작은 반경으로 설정)
   - 캐릭터 등에 무제한으로 쌓이는 비주얼(스택 배열 관리, 위치 오프셋 순차 배치)
3. 소켓 흡수 및 소환 이벤트는 **아직 구현하지 말고**, `SocketReached`, `SocketAbsorbed`, `SocketFilled` 이벤트 이름만 인터페이스로 비워둔 채(스텁 처리) 나중에 이어붙일 수 있게 구조만 잡아줘.

## 참고해야 할 기술적 배경 (이전 세션에서 확인된 사항)

- 이 프로젝트는 Cocos Creator HTML5 컴파일 빌드이며, 프로덕션 트리쉐이킹으로 `cc` 전역에서 일부 Component 클래스가 빠져있을 수 있음 — 필요 시 `node.addComponent('cc.ClassName')` 문자열 방식으로 우회 가능.
- 이 런타임에서는 `AnimationClip`/Track 시스템이 정상 동작하지 않는 경우가 있었음(`cc.animation` 네임스페이스 부재, `trackCount: 0`) — 코인은 애니메이션 클립 없이 정적 메쉬로 제작하고 회전/튐 등은 `cc.tween`이나 `update()`에서 코드로 처리할 것.
- 코인 3D 모델은 Blender에서 glTF로 익스포트 시 Backface Culling을 켜서 `doubleSided: false`로 내보낼 예정(용량 최적화).
- 이벤트 버스(EventTarget) 기반으로 각 단계를 느슨하게 연결하는 구조를 권장함: `MonsterKilled → CoinSpawned → CoinCollected → StackChanged → (이후 소켓 관련 이벤트는 스텁)`.
