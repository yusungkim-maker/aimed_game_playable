# 건물 통일 수정 v2

6개 시설 × 4개 변형 × 본체/그림자 = RGBA PNG 48개.

- `Body.png`: 지면 그림자가 없는 본체.
- 같은 이름의 `Shadow.png`: 검정색 그림자만 있는 레이어, 최대 알파 89/255 (약 35%).
- 모든 PNG: 1024×1024. 본체와 그림자는 같은 위치·크기·앵커로 겹쳐 사용합니다. 파일별 자동 트리밍을 적용하면 정렬이 달라질 수 있습니다.
- `Left45` / `Right45`: 건물 전면이 화면 왼쪽 아래 / 오른쪽 아래를 향하는 두 방향.
- 일반 건물: `Basic` / `Expanded`. 광산: `Active` / `Inactive`.
- 광산의 같은 방향 상태 쌍은 산 본체와 외곽 알파가 동일하고 입구 내부만 다릅니다. 그림자도 완전히 동일합니다.
- 기본 지면 기준점: 이미지 왼쪽 위 기준 (360, 820). 이 좌표는 레이어 정렬용 공통 기준이며 3D 메시의 실제 바닥 피벗을 측정한 값은 아닙니다.

## 스타일 및 카메라 기준

사용자가 제공한 대장간 이미지를 화풍 참고로 사용했습니다. 단순한 큰 면, 작은 베벨, 목재 중심 색, 절제된 회색 금속·돌과 청록 포인트를 유지하고 과도한 장난감 질감과 세밀한 나뭇결을 줄였습니다. 생성 원본 외곽의 저알파 색 번짐 및 얇은 테두리는 픽셀 후처리로 정리했습니다. 재질의 접합부·면 음영은 유지했습니다.

공통 생성 지시: 원근 없는 오소그래픽 카메라, 내려보기 45°, 수직 Z축 회전 ±45°. 동일 투영 가이드 및 기준 건물 이미지를 사용해 세트 내 시점을 맞췄습니다. 생성 이미지 기반이므로 수치적으로 정확한 3D 카메라 렌더 결과는 아닙니다.

그림자는 전체 실루엣을 화면 오른쪽 수평에서 위로 15° 방향으로 투영해 별도 생성했습니다. 본체에 가려지는 부분까지 포함하되, 원본에 없는 3D 깊이 정보는 근사한 그림자입니다. 광산의 상태별 그림자는 같은 파일 내용입니다.

판매대에는 지붕·천막·높은 기둥을 두지 않았습니다. 고용소에는 접수 창구·모집 게시판, 대장간에는 모루 표식·화덕·굴뚝을 배치했습니다.

제작: 내장 이미지 생성 도구 + 사용자 승인된 Python 픽셀 분리/정합/외곽 정리.

`전체_비교.jpg`는 확인용 배경 합성입니다. 실제 에셋 PNG의 배경은 투명합니다.
