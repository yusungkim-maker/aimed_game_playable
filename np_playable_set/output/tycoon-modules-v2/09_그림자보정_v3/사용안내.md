# 그림자 보정 v3

본체 24장은 v2 PNG와 바이트 단위로 동일합니다. 그림자 24장만 다시 제작했습니다.

## 적용

- 같은 이름의 `Body.png`와 `Shadow.png`를 동일한 위치·크기·앵커로 겹칩니다.
- 모두 1024×1024 RGBA PNG. 별도의 자동 크롭/트리밍이나 레이어별 크기 맞춤을 하지 않습니다.
- 그림자: 검정 RGB, 최대 알파 89/255 (약 35%), 선명한 경계.
- 광산 활성·비활성의 같은 방향끼리 외곽 알파와 그림자가 동일합니다.
- 각 건물 폴더: 본체 4장 + 그림자 4장 = 8장. 전체 48장.

## 수정 방식과 검증 범위

v2의 실루엣 전체를 단일 바닥선으로 압축하던 방식을 폐기했습니다. 건물마다 바닥 접점, 기둥과 벽, 처마, 지붕 능선, 굴뚝, 모루, 깃발 등 주요 부분에 높이·깊이 제어점을 맞춰 표면을 복원하고, 평행 광선과 지면 Z=0의 교차점으로 그림자를 계산했습니다. 본체와 같은 좌표계에 재투영하므로 접점과 레이어 정렬을 유지합니다.

공통 광원: Blender Sun / XYZ Euler **X=0°, Y=-27°, Z=20°**. Sun의 local -Z 방향을 회전한 월드 광선 벡터는 대략 `(0.42661154, 0.15527390, -0.89100653)`입니다. Blender 5.2에서 실제 Sun 오브젝트를 생성해 확인했습니다. 카메라는 원근 없는 ORTHO, 수평에서 45° 내려보기이며 이 좌표계에서 지면 그림자의 진행 방향은 화면 오른쪽 수평보다 약 14.43° 위입니다. Sun Angle=0 기준의 선명한 경계를 사용했습니다.

원본은 생성된 PNG이므로 이 깊이 정보는 수동으로 맞춘 2.5D 근사입니다. 실제 원본 3D 메시를 렌더한 것과 동일하다고 보장할 수는 없습니다. 광원 회전값 및 투영 계산은 공통이며, 복원한 건물 형상에 대한 그림자입니다.

검증: 본체 24장 원본 해시 일치, 레이어 캔버스·정렬 유지, 광산 상태별 그림자 일치, 모든 본체·그림자 합성 육안 확인. `메인기지_수정전후.jpg` 및 `전체_그림자_확인.jpg`는 확인용입니다.

참고: [Blender Sun Light 설명](https://docs.blender.org/manual/en/latest/render/lights/light_object.html).
