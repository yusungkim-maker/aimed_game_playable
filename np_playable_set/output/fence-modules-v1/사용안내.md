# 울타리 모듈 v1

- `Fence_Modular_Set.blend`: 편집용 원본, 4방향 연결 예시, 카메라와 Sun 포함.
- `Fence_Decorative_Post.glb`: 꼭짓점/끝점용 장식 기둥.
- `Fence_Connection_3m.glb`: 기본 연결 모듈. Blender 로컬 X축 기준 길이 3m.
- `Fence_Connection_045/135/225/315.glb`: Blender Z축 회전이 포함된 방향별 사본. 이미 회전이 포함되어 있으므로 추가로 같은 각도를 더하지 않습니다.
- `Fence_Preview.png`: 4방향 연결 렌더.
- `build_fence.py`: 재생성용 Blender Python 스크립트.

## 편집과 연결

Blender의 `01_Modules_EDIT_HERE` 컬렉션은 예시와 겹치지 않도록 뷰포트와 렌더에서 숨겨져 있습니다. 원본을 편집하려면 해당 컬렉션을 켜고 `02_Four_Directions_Demo`를 숨기세요. 예시는 원본과 메시 데이터를 공유하므로 Edit Mode의 형상 수정이 함께 반영됩니다. 오브젝트 위치/회전은 별개입니다.

기둥 원점은 바닥 중앙입니다. 연결 모듈 원점은 구간의 바닥 중앙이며 끝점은 로컬 X=-1.5, +1.5입니다. 두 끝점에 기둥 중심을 맞추세요. 양쪽 가로대가 기둥 내부로 들어가므로 이음새가 드러나지 않습니다. 기둥 중심 간격은 3m입니다. 전체 크기를 바꾸려면 기둥과 연결 모듈에 동일한 배율을 적용하세요.

Blender는 Z-up이고 GLB는 Y-up으로 변환해 내보냈습니다. 방향 숫자는 Blender 지면 기준 Z 회전입니다. Cocos의 Y 회전에 같은 숫자를 그대로 넣는 의미는 아닙니다.

## 외형과 조명

목재색, 무광 회색 금속 캡, 석재 받침, 작은 베벨을 사용합니다. 텍스처와 외곽선은 없습니다. 카메라는 오소그래픽 내려보기 45도, Sun XYZ Euler=(0,-27,20)입니다. 확인용 바닥/카메라/조명은 GLB에 포함하지 않았습니다.

그림자는 모델에 구워 넣지 않았습니다. Cocos에서는 씬의 조명과 그림자 설정을 통해 생성해야 하며, Blender의 Euler를 다른 좌표계에 그대로 복사하면 방향이 달라질 수 있습니다. 실제 Cocos 배치/머티리얼/그림자 확인은 아직 진행하지 않았습니다.
