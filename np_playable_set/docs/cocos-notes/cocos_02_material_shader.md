# Cocos Creator 3.8 — 머티리얼 / 이펙트 / 셰이더

## 1. 구조: Material → Effect → Pass → Shader

- **Material**: 실제로 오브젝트에 적용하는 "설정값 묶음" (텍스처, 색상, 파라미터 등). 어떤 Effect를 쓸지 지정하고 그 Effect가 노출하는 파라미터에 값을 채운다.
- **Effect (`.effect` 파일)**: 렌더링 방식을 정의하는 파일. 여러 개의 **Pass**로 구성된다.
- **Pass**: 하나의 렌더 패스. Vertex/Fragment 셰이더 코드와 렌더 상태(blend, depth test, cull mode 등)를 담는다.
- **Shader**: Cocos는 **GLSL 기반**의 자체 프레임워크 "Cocos Shader"를 씀. Unity의 ShaderLab(HLSL/CG)과 문법이 완전히 다르므로, Unity 셰이더를 그대로 가져올 수 없고 새로 작성해야 한다.

셰이더 작성 방식은 3가지 층위가 있음:
1. **Surface Shader** — 공통 렌더링 요구를 고수준으로 추상화 (가장 쉬움, PBR/Toon 등 표준 패턴에 적합)
2. **Legacy Shader** — 구버전 호환용
3. **Custom Shader** — GLSL 직접 제어 (Fresnel, 커스텀 이펙트 등 세밀한 제어 필요 시)

## 2. Sprite vs Custom Material (2D UI 관련)

일반 UI 이미지는 `Sprite` 컴포넌트 + `SpriteFrame`만으로 충분 (별도 머티리얼 작성 불필요, 엔진 기본 UI 셰이더 사용). 특수 효과(디졸브, 색상 반전, 아웃라인, Fresnel 등)가 필요할 때만 Custom Material을 만들어 붙인다.

## 3. Fresnel / Rim Light 구현 시 성능 고려사항

Fresnel 효과를 "켰다 껐다" 해야 하는 경우, 다음 세 방식의 트레이드오프:

- **오브젝트 1개 + 셰이더 내 uniform 토글**: 가장 가볍다. 드로우콜 추가 없음, uniform 값 하나로 셰이더 분기.
- **오브젝트 2개(일반+Fresnel)를 겹쳐서 교차 표시**: 메쉬/드로우콜이 사실상 2배가 되어 용량·성능 모두 손해. 특별한 이유가 없으면 비추천.
- **머티리얼 스왑(같은 오브젝트에 다른 머티리얼 교체)**: uniform 토글보다는 약간 무겁지만(머티리얼 인스턴스 전환 비용), 오브젝트 중복보다는 낫다.

결론: 대부분의 경우 **1번(uniform 토글)**이 용량/성능 면에서 가장 효율적.

## 4. 라이팅 / 그림자와 용량·성능의 관계 (중요한 구분)

- **빌드 용량(다운로드 크기)**: 셰이더 코드 자체는 텍스트라 라이팅/쉐도우 로직을 추가해도 몇 KB 수준 증가에 그친다. 텍스처 용량에 비하면 무시할 만한 수준. (단, 라이트맵을 굽는(bake) 방식이면 별도 텍스처 이미지가 생겨 실제로 용량이 늘어난다 — 실시간 라이팅과는 다른 케이스.)
- **런타임 성능(씬이 무거워지는 것)**: 라이팅은 픽셀당 조명 계산이 추가되는 정도라 비교적 가볍다. 반면 **실시간 그림자(shadow map)는 씬을 그림자 카메라 시점으로 한 번 더 렌더링하는 별도 패스**가 추가되어 드로우콜/GPU 부하가 크게 늘어난다. 모바일 WebGL(플레이어블 광고가 돌아가는 웹뷰 환경) 환경에서 프레임 드랍의 주요 원인.
- **실용적 절충안**: 실시간 그림자는 끄고, 필요하면 오브젝트 발밑에 반투명 원형 스프라이트(blob shadow)를 깔아 접지감만 흉내낸다 — 텍스처 한 장 비용으로 그림자 느낌을 낼 수 있음.

## 5. 빌드에서 발견되는 불필요한 런타임 번들 주의

Cocos 번들러는 프로젝트 어디든 Spine 관련 컴포넌트/에셋 참조가 하나라도 있으면, 실제로 그 씬에서 안 쓰더라도 Spine 2D 런타임(`SpineWasmUtil`, `spine.wasm` 등, wasm만 약 200KB + JS 글루코드)을 통째로 번들에 포함시킨다. 프로젝트가 Spine이 아니라 Cocos 네이티브 애니메이션(SkeletalAnimation/glTF)만 쓴다면, Spine 관련 잔여 참조를 제거해 용량을 줄일 수 있는지 점검할 가치가 있다.
