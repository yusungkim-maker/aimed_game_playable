## 3. 진행 순서 【확정】

```
[0] 시작 — 기지 + 플레이어만 중앙에 있다
      |
      v  플레이어가 직접 벌목
[1] "일꾼 생성 건물" 해금                                   (나무 소비)
      |  · 소켓 A1 : 플레이어가 서 있으면 일정 시간마다 나무 일꾼 1명
      v                                                    (나무 더 소비)
[2] "나무 창고" 건설
      |  · 소켓 B1 : 일꾼이 캐 온 나무가 창고 앞에 쌓인다
      v                                                    (나무 더 모음)
[3] "광산" 해금  ← 동시에 3가지가 바뀐다
      |  (a) 소켓 A2 추가 → 일꾼이 2종 분화 (나무 일꾼 / 철 일꾼)
      |  (b) 철 일꾼도 플레이어가 A2에 서 있으면 시간당 배출
      |  (c) 소켓 B2 추가 → 창고 앞에 철도 쌓인다
      v                                                    (철 + 나무 동시 소비)
[4] "대장간" 건설
      |  · 플레이어가 창고의 나무·철을 **등에 싣고** 대장간으로 옮긴다
      |  · 대장간이 두 재료를 합성해 **칼을 1개씩 제작**
      v
[5] "상점" 건설  ← 이 시점에 레일 소켓 2개가 한꺼번에 생긴다
      |  · 플레이어가 칼을 **등에 싣고** 상점으로 옮겨 가져다 놓는다
      |  · 손님이 와서 칼을 사고 **돈을 지불** → 소켓 C에 쌓인다
      |  · 소켓 D1 · D2 생성 (아직 잠김)
      v                                                    (돈 소비)
[6] 레일 자동화 — 플레이어의 운반 노동을 대체한다
         · D1 해금 → 레일: 창고 ──(나무·철)──> 대장간
         · D2 해금 → 레일: 대장간 ──(칼)──> 상점
```

## 4. 소켓 정리 — 역할이 4종류다

| # | 소켓 | 개수 | 위치 | 하는 일 | 생기는 시점 |
|---|---|---|---|---|---|
| **A** | 일꾼 생성 | 1 → **2** | 일꾼 생성 건물 | 플레이어가 **서 있으면** 시간당 일꾼 1명 배출 | [1]에 A1(나무) → [3]에 A2(철) |
| **B** | 창고 적재 | 1 → **2** | 나무 창고 **앞** | 일꾼이 캐 온 자원이 **쌓인다** | [2]에 B1(나무) → [3]에 B2(철) |
| **C** | 돈 적재 | **1** | 상점 **옆** | 손님이 낸 돈이 쌓인다 | [5] 상점 건설 |
| **D** | 레일 해금 | **2** | 각 운반 구간 | 돈을 넣어 해금 → 그 구간에 레일이 놓여 자동화 | [5] 상점 건설 시 **둘 다 한꺼번에** 생성 |

**레일 구간은 정확히 2개다** 【확정】 — 플레이어가 직접 옮기던 구간이 둘뿐이기 때문:
- **D1: 창고 → 대장간** (나무·철)
- **D2: 대장간 → 상점** (칼)

> ⚠️ 기존 `Socket`은 "요구치 충족 → 건설" **한 가지 동작뿐**이다. **A·C·D는 그대로 못 쓴다.** 【추론】
> - A = "서 있으면 시간당 산출" (기존에 없는 방식)
> - B = 기존 `CoinGroundStack`(창고 적재)에 가깝다
> - C = 적재이지만 손님이 채운다
> - D = 요구치 충족형이라 기존 `Socket`에 제일 가깝다

## 6. 아직 정해지지 않은 것

1. **대장간의 소켓 구성** — 플레이어가 재료를 놓는 곳과 완성된 칼이 쌓이는 곳이 따로 필요해 보인다. 몇 개이고 어떻게 생겼는지 【미정】
2. **상점의 칼 적재 소켓** — 플레이어가 칼을 "가져다 놓는" 자리 【미정】
3. **합성 비율** — 나무 몇 개 + 철 몇 개 = 칼 1개? ("1개씩 제작"은 산출이 1개라는 뜻으로 읽었다) 【미정】
4. **레일 해금 비용** — 돈 몇 개씩? D1과 D2가 다른가 【미정】
5. **손님(NPC)** — 어디서 오는지, 주기, 외형, 칼 1자루당 지불액 【미정】
6. **상점 건설 비용** 【미정】
7. **일꾼 생성 주기·상한** — 무한정 늘어나는가 【미정】
8. **엔딩 조건** — 플레이어블 광고이므로 어디서 끝나고 CTA가 뜨는지 【미정】

## 7. 현재 구현 상태와의 차이

| 항목 | 현재 | 명세 |
|---|---|---|
| 자원 | 나무만 동작 (`Choppable` → `ResourceDropped`) | 나무 / 철 / 코인 3종 |
| 창고 | `Warehouse`(`CoinGroundStack`) 1개, 배선 완료 | 앞에 적재 소켓 2개(나무/철) |
| 일꾼 | `CoinCourierManager.routes`가 **빈 배열**이라 안 나옴 | 소켓에 서 있으면 시간당 생성, 2종 분화 |
| 소켓 | `SocketManager.sockets`가 **0개**라 하나도 안 나옴 | A/B/C/D 4종 역할, 총 7개 |
| 달구지 | 2026-09-17에 `T_Player`와 씬 `Player`에 노드만 추가(꺼둠). `T_Worker`에는 **없음** | **일꾼 전용 — 플레이어는 안 쓴다** → 옮겨야 함 |
| 플레이어 운반 | 등 뒤 `CoinStack` 있음 | 그대로 사용. 나무·철·칼 세 종류를 실어야 함 |
| 대장간·상점·광산·레일 | 전부 **없음** | 신규 |
